## 数据库接入与导入

当前数据保存在 SQLite 中，可以交换兼容的数据库并通过已有入口打开使用；受支持的旧表结构由 initialize_database 显式升级。运行封装仍使用对应的 TOML 与 Python 类，这些代码和配置不存放在数据库中。

以后如果需要接入其他版本或派生项目的数据库，优先沿用现有数据库结构与升级机制，明确兼容关系。当前不新增 JSON 项目导入、另一套交换格式或通用迁移框架。

只有在确实需要把多个数据库的部分数据合并到一个库时，再讨论选择范围、编号映射、跨库关联和配置对应。这与直接打开一个兼容数据库是两件事，暂不实现。
