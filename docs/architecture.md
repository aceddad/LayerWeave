# LayerWeave 架构

本文说明模块之间的关系。具体字段、调用和规则由所链接的专题维护。[返回项目首页](../README.md)。

## 基础概念

Layer 组织上下文并装载 Object；Object 保存具体内容及其在轴上的位置。层形成父子结构，bind 表达层或对象之间的关联，可跨项目引用。

Python 类表达封装类型，TOML 描述该封装的标识、内容字段与约定。name 是实例的用途名称；type 来自 TOML。模型与配置的扩充入口分别是[models](../src/models/README.md)和[configs](../configs/README.md)。

层配置的 tools 记录外置 skill 的 route、tier、when，供 AI 选择并查阅；这是原型的能力说明，独立于软件内部工具。声明由 help 原样展示，具体格式见[层配置](../configs/layers/README.md#外置技能-tools)。

项目提供实体身份的上下文。层与对象的数据、结构关系和自由内容由存储层保存；编号与关联规则见[存储专题](../src/runtime/storage/SCHEMA.md)。

## 模块关系

```text
使用方 / 内部工具 / 将来的视图
                 ↓
             runtime.api
                 ├─ 只读查询与模型装载
                 └─ 写入事务、编号、日志
                              ↓
                        提交后的约定检测
```

配置读取器为装载、工具说明和检测提供有效配置。存储与检测职责分开：SQL 结构约束在写入时生效，语义诊断在提交后报告。反馈格式见[请求协议](../src/tools/usage/CRUD.md)，触发时点见[检测专题](../src/runtime/validation/RULES.md)。

内部工具共用核心能力，分为使用、开发和视图三类，shared 提供共用支持。详细展开与文本汇集属于内容查询，能够在没有界面的环境下运行。

## 解释边界

轴的单位由调用方解释，工具不自动换算时间、帧或其他单位。位置计算、存储和查询的具体约定见[使用手册](../src/tools/usage/GUIDE.md)与[编辑专题](../src/tools/usage/EDITING.md)。

information 保存内容；source 资源引用原样保留。通用工具不推断媒体切片、不复制资源文件或改写自由内容中的编号。需要解释某类资源时，在对应的使用工具中扩展。

可视状态由未来视图管理，基础模型不保存 visible；visibility 配置描述显隐控制能力。视图修改内容时仍调用核心和使用工具，边界见[视图说明](../src/tools/view/README.md)。

## 版本与后续

非可视化 main 长期独立可用，早期源码基线标签为 core-v0.1.0。可视化开始时建立独立 visualization 分支，通用改进继续维护在主线。

Git 保存源码与配置，标签不代表用户数据快照。实际数据库与资源单独保存。待讨论方向见[后续候选](FUTURE.md)，MCP 入口编排留到封装阶段。
