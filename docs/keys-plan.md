# 本地 KEY 管理工具

以名称标识 KEY 条目，使用 JSON 保存 key、env_name、base_url、model 和 used。used 记录任意使用方，是指引，不是权限或技能专属绑定。

## 范围

- 默认真实文件为用户目录的 .layerweave/keys.json，可通过 store 指定；这是本地明文 JSON，不是加密密钥库。
- 第一版使用标准库，无远程服务、自动探测、技能扫描、执行器或全局环境变量修改。
- 普通查询只返回元信息与 key_configured；程序通过 get_key 读取实际值。
- 示例导出保留名称和 used，将 key 置空，并将环境变量名、地址和模型替换为固定中文提示。
- 初始化从示例建立空条目，不覆盖已有本地文件。初始真实 KEY 由用户之后注册，本次不创建用户的真实密钥文件。
- KEY 文件属于工具自己的本地配置，不进入项目数据库和 changes 日志；原有统一写门继续管理业务数据库。
