# 三层整理设计与迁移计划

本文件保留本次重构的边界与验收记录。现行边界以[架构说明](architecture.md)为准，开发与运行方式见[开发指南](developer-conventions.md)。

## 已确认的边界

- 抽象核心保留 Layer/Object、身份、关系、封装与继承语义，不依赖 SQLite、TOML 读取或工具。现有 models/layers 与 models/objects 分区保留。
- 基础支撑负责 TOML 读取与约定合并的适配、实例装配、SQLite、原始读取、发号、事务和日志。config_ref 仍是相对配置根目录的稳定引用，不迁移为新的类型 ID。
- 普通位置写入统一按轴精度落点，无精度时为 1e-6；迁移和恢复通过明确的原值写入能力保留历史值。
- 所有受支持的写操作经过同一事务入口；编号、记录与日志共同提交。恢复原编号也经过此入口，不能降低发号进度。
- 父链成环在事务最终状态拒绝提交。基础类不增加赋值检测，原始读取仍可用于查看旧库中的问题数据。
- CDUR 请求协议、帮助、内容检测、历史展示、撤销决策、编辑操作属于可替换工具。没有检测包时照常写入，并明确标记未检查。
- 内置工具放 tool/builtin，外置技能保持 tool/skills。技能 route/tier/when 只供 AI 阅读；不自动执行或绑定。
- 共用 CLI 外壳、命令声明发现和示例排版属于支撑层，不依赖某个可卸载的 help 包。

## 目录与包粒度

```text
src/core/                         抽象定义与纯数据语义
src/models/layers|objects/        基础类及默认派生类，保持当前类路径
src/support/                      存储、配置、实例装配、CLI 等基础支撑
tool/builtin/usage/
  records/                        CDUR 与默认保存入口
  query/                          概览、展开、检索、关系、空档查询
  editing/                        位置、对象、子树、分割、插空档、迁移
  history/                        历史展示与差异
  undo/                           撤销计划与冲突判断
  validation/                     可替换的数据规则与复查
  text/                           文本汇集
tool/builtin/shared/help/         配置与命令帮助
tool/builtin/developer/           数据库准备、技能 ZIP 安装等独立包
tool/builtin/view/                仅保留说明
tool/skills/                      外置技能，不属于内置命令发现范围
```

一个完整包携带自己的业务辅助代码；跨包不引用私有函数。默认检测通过显式、可选的公共提供者接入，其缺席不妨碍其他工具写入。支撑层仅发现与调用提供者，不硬编码业务规则。

## 统一写入入口

入口负责操作编号、事务和真实变更收集。工具决定要改什么；支撑层通过创建、更新、删除、按原身份恢复四种写能力实际落库。

- 创建默认发号；恢复可保留已有身份，仍检查结构冲突并维护发号上界。
- 读取、比较和修改可以在同一次操作里完成，避免撤销冲突检查和恢复之间使用过期状态。
- 日志由实际写入产生，不信任工具自行拼装的日志或变更列表。
- 父引用存在、所属关系等继续由存储结构保证；父链无环在提交前按本批关系变化的最终状态检查。
- 内容类型、重叠、时长、字段缺省等仍由可卸载检测包负责。检查在提交后执行，失败不会伪装成写入失败。
- 业务工具不执行 SQL 写入；SQLite 细节封装在支撑层。直接操作私有适配器不属于受支持的工具接口。

## Python 入口

新增本地可编辑安装配置，在项目环境执行 `python -m pip install -e .`。src 下的核心/支撑/模型与 tool/builtin 下的工具均由明确的包配置导入。开发命令统一从项目根运行，另验证从其他工作目录也可调用。

不维护旧模块路径转接，不发布安装包，不加入热插拔或多存储后端。

## 验收

1. 只保留抽象核心和模型，可以独立导入、表达封装语义并运行核心测试。
2. 不存在任何内置工具时，核心与支撑仍能读写、发号、记录日志，并完成 Title 等实例往返。
3. 每次只安装一个完整内置包，能发现它的命令并实际完成一次代表性调用；必要的通用辅助由支撑提供。
4. 全部默认包存在时，原有功能回归通过；成环测试按已确认的新拒绝行为更新。
5. 验证原值恢复、事务失败回滚、编号不回收、无工具检查状态，以及工具外目录启动。
6. 测试和示例使用临时数据库，不修改 output 内的数据或外置技能。
