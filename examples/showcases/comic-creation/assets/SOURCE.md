# 素材来源与使用

本目录所有 SVG 为本案例原创矢量绘图，剧情、对白和人物均为本案例原创。未使用外部图片、角色、模型或网络素材。可随本案例复制、分发、修改；本案例原创内容按 CC0 1.0 贡献，无署名要求。

- `panel-01.svg` 至 `panel-08.svg`：当前八格，720 × 500。
- `panel-07-draft.svg`：第七格旧对白的实际候选画面，未采用。
- `page-01.svg`、`page-02.svg`：两张完整页面，1544 × 1320，每页嵌入四格矢量内容，无外链图片。
- `page-01.png`、`page-02.png`：SVG 页面对应的便携预览，若仅改 SVG 则须重新导出 PNG。

SVG 本身即编辑源文件，气泡文字使用 `<text>`，可在文本编辑器或矢量编辑器中修改。页面中的分格用 `data-panel` 标记。单格与整页各自包含完整矢量内容，修改单格不会自动同步整页。系统字体优先 Microsoft YaHei，其次 Noto Sans CJK SC / PingFang SC；未附带字体文件，跨系统可安装任一中文字体。PNG 预览不依赖查看者安装字体。
