# 草图来源与编辑

`01-availability.svg`、`02-confirm.svg`、`03-my-booking.svg` 为本案例原创的中文界面线框图，未使用第三方图片、模板、商标、外链字体或生成图片服务。项目名称、人物、日期和业务数据均为虚构。

每份文件使用 SVG 原生文本、矩形和样式，尺寸 1440 × 1000。SVG 本身即完整可编辑源文件；浏览器可直接打开，文本编辑器或支持 SVG 的矢量编辑器可改文字和布局。无脚本、无远程请求，所有按钮只表达交互设计。

字体依次使用 Microsoft YaHei、Noto Sans CJK SC、系统 sans-serif；字体不随文件分发。查看环境需有可显示中文的字体。修改前可自行保留副本。

允许将这些原创 SVG 随本案例复制、修改和再分发。移入其他目录时同步修改 `project.json` 中的 `information.source`；文件相对数据库目录解析。黄色区块表达刻意保留的迟到策略决策缺口，不表示产品已实现。
