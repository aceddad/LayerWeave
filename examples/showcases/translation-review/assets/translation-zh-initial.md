# 留下那声咔哒（初译，保留比较）

版本：完整初译。为对照保留部分直译、术语不一致与语境误译；不是当前推荐稿。对应 project.json 的“中文初译（保留比较）”根。

亲爱的玛雅：

昨天我在冬天的毯子后面找到了父亲的收音机，外面裹着那条蓝边毛巾。你让我在清空房子之前发些照片，但这件东西似乎值得写一封信。在照片里，它看上去就是一个普通木盒，一角被一只谁也不承认放过的杯子染深了颜色。你看不到转动调台旋钮与听到人声之间那短短的延迟。那段停顿是我们夜晚的一部分。父亲用它拉开椅子，母亲用它问有没有人还想喝茶。

收音机附有一本服务手册，我在最底层抽屉的一捆旧收据下面找到了它。父亲在页边写了日期，又仔细地在一颗螺丝旁画了个圈。我以前以为，这些标记是在教人怎样让东西永远用下去。现在看来，它们更像是他愿意重新开始的记录。他可以花整整一个星期六查找故障，然后接受一个不完美的结果，并不失望。即使修过以后，电台之间仍有一点静电。他从不把这叫作失败，只是把音量调低。

今天早上转动调谐旋钮时，熟悉的咔嗒声带回来的不是一个电台，而是那间狭窄的厨房，你站在椅子上够架子，而我假装自己已经足够高了。我记得你的袖子擦过面包，潮湿的窗玻璃，以及天气预报开始时我们压低声音的样子。我不记得预报本身了。也许记忆对保存信息的兴趣不如对保存陪伴的兴趣。那声咔嗒只持续了一瞬间，但就在那一瞬间，我不觉得自己像是在独自整理房子。

我把收音机送到桥边的修理店。柜台后的女士问我，是否想让它看上去像新的一样。她可以更换扬声器上的布，磨掉木头上浅色的圆环。我听见自己说：“让它安全，但留下咔嗒声。”她笑了，没有让我解释，就把这句话写在维修单上。我也把服务手册留给了她。保留旧笔记有实际的理由，即使写下它们的人已经不能再回答问题。并非每一道痕迹都是损坏，也并非每一次改善都是好意。

在你开始担心之前，我并没有把房子变成博物馆。我把开裂的碗送给种香草的邻居，也让送货司机拿走了那张我们都不喜欢的桌子。保留一切会让人难以在这里生活；什么都不留，又会让离开显得比实际更容易。收音机足够小，可以放在我的窗边。我想通过它听到陌生的声音，连同那些静电，让新的夜晚聚集在旧的夜晚周围。一件物品可以承载一段记忆，而不必被要求承载我们的全部过去。

下个月你来时，如果找得到，就带上你在海边录的那盘磁带。我知道收音机不能播放它。我们可以借一台播放机，轮流听这两台机器，让它们各自在桌上占一个位置。你可以在我泡茶时转动调台旋钮。我们可能会对父亲更喜欢哪个电台意见不一；我们一直都是这样。我不需要收音机来解决那个问题。我只想要一件我们讲述各自版本时可以坐在旁边的东西，以及当我们谁都没什么可说时的一点寂静。那片寂静里，仍然有我们的空间。

爱你的，
丹尼尔
