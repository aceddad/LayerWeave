# 视图使用指南

画布操作与 AI 协作从本页查找。[返回视图首页](README.md)。中英切换、复制语言和截图 `--lang` 见[语言包](LANGUAGES.md)。

## 网页操作

```sh
python -X utf8 -m layerweave.tool.builtin.view.server DATABASE --project PROJECT_ID --port 8765
```

DATABASE 替换为实际数据库路径，PROJECT_ID 替换为已存在项目编号；省略 --project 时选择默认项目。用浏览器打开打印出来的地址。

### 画布

一张可以拖动、缩放的画布。每个根层连同它的子树是一块**画板**，画板里是这个根的时间轴：层按父子顺序排成轨道；对象是轴上的色块。同一层里互相重叠的对象会分成上下几行。两个对象之间空着的地方画一条标尺 `|— 3.000 —|`，写出空了多长，位数按这个根的轴精度（精度 0.001 写三位小数，按帧的写整数）；太窄放不下数字时只画两头的竖线，第一个对象之前、最后一个之后不画。图片显示缩略图，视频片段够宽时左边是第一帧、右边是最后一帧（窄的只显示开头），音频显示波形，文字直接显示；文件不存在的对象用斜纹标出。配置里 `display.default_visible = false` 的层（比如批注层）默认不进画布。
尺子刻度使用轴精度的整数倍：精度为 1 的序号轴不会因放大而出现 1.2 之类的刻度。组合画板使用参与根层中最细的精度；未声明精度时按基础默认值 1e-6 处理。各根自己的精度和对象位置不会被修改。已知秒单位（如 second、seconds、s、秒）在中文界面显示“秒”，英文显示“s”；自定义单位保留原文，数据库中的单位值不变。

### 尺寸与共享排版

选中画板后，拖动边框或角上的句柄调整宽高；标题栏的“对象行高”可快速选择紧凑、标准、阅读或大图。拉宽改变每个轴单位的显示宽度，拉高增加对象的显示行高。文字在更大的格子内换行，较高的文字格显示标题与正文；对象 begin/end、层归属和轴单位保持原值。重叠对象仍按实际需要分成多行。

同一块画板共用横向比例。合并时最上方、最左端的根提供横向比例；未设明确比例时，按当前组合范围计算默认宽度。左右接续的同名轨道采用最左侧来源的行高。上下排布保留各根行高。合并本身保留成员偏好，拆出恢复；对整个组合执行尺寸调整，则会明确调整组合内各根的尺寸偏好。

首次显示的默认内容跨度宽 1000 个画布像素，便于网页与无界面工具计算相同边界；“适应”按钮按当前窗口设置横向比例。镜头缩放与这些画布尺寸分开。普通位置移动允许叠放，现有吸附与内容变高后的避让继续生效。

位置、尺寸和组合保存在项目库的视图工具表中，编辑经过统一写入入口，有操作日志，可用现有撤销工具恢复。拖动过程中不逐帧写库，松手时保存一次。首次打开、自动预览和截图不把默认排版写入数据库。JSON 交换导出包含这些工具表时，可以把布局随项目带走。

旧本机 layout.json 仍可读取。第一次编辑或显式执行 `view_layout migrate` 时保存当前布局到库，保留旧文件；库里已有布局时优先读库，不用本机旧文件覆盖其他人的共享布局。

### 目录

（画布左边，可以收起，记在本机）：项目的层按 根 → 层 → 子层 列出来，画面外的、折叠起来的也在。每行写层名、类型、对象数（有子层时写"自己的 / 连同下面的"）、谁折叠的、💬 几楼批注没处理（指着这一层、它的对象或下面的层）。
  - 点层名：镜头过去，这一层被选中（和点画板上的层名一样，写批注时指向它）。层在折叠的层下面、或者被"只看"滤掉了时，会提示不在画布上。
  - ▾/▸ 只在目录里收起，不动画布上的折叠；要折叠画布上的层，用每行右边的「折叠」（鼠标移上去才出现），和画板层名列上的折叠是同一件事。
  - 勾选：勾一层连同它下面的层，就是"选了一组"，不会把别的层藏起来。顶上的「只看勾选的」让画布只显示这几层（和截图的 `--layers`、链接里的 `layers=` 是同一个，复制链接会带上），再点一次恢复；「折叠勾选的」一次在你这边折叠它们。插件也读得到勾了哪几层。
  - 点对象数：列出这一层的对象（最多 200 个），点一个就选中它。
### 折叠

人和 AI 各有各的折叠，互相看得见。每一层名字前都有 ▾，点一下收起这一层和它下面所有的层，只剩一条细条：层名带橙色边框，内容处是一条虚线框，写着"已折叠 · 下面 2 层 · 5 个对象 · 💬 1 楼待处理（用户 折叠的：备注）"，可以在上面写备注；画板标题上写"折叠了几条"。点 ▸ 或细条展开。左右接续时合成一条的轨道，折叠会折叠它包含的每一个层。
  - **AI 折叠的**在你的页面上照常展开，层名旁标着"AI 折叠"，轨道右上角写着"Claude 折叠了：原因"；点标签上的 × 让 AI 也展开。AI 新折叠了什么，右下角会提示。
  - **你折叠的**在 AI 的截图里照常画出，标着"用户折叠了"：AI 照常检查里面的内容，只知道你现在不关注它。AI 也能把你折叠的层展开给你看，写了理由就会在那一层留一条批注，你收到提示，可以在楼里回它。
  - 折叠存在数据库里视图自己的表（见[数据结构](DEVELOPMENT.md#折叠表视图自己的表)），下次打开、换一个 AI 来看，都还是这样。画板变高变矮时，下面的画板跟着推开或收拢。地址加 `?as=ai` 可以看 AI 那边的样子（只看不改折叠）。
### 拼接

单位相同的根才能拼。"秒"和"s"这类同义写法算同一种单位；没有单位的根各占一块，不参与拼接。
  - **上下 = 同时**：几行共用一把尺子和一根播放头，同一个数值上下对齐。单位相同的根默认就这样拼在同一块画板里。
  - **左右 = 接续**：后一个根的 0 接在前一个根的结尾（比如第二章接在第一章后面），画板上用连续的时间；两段里名字相同的层合成一条轨道（第一章的「字幕」后面接第二章的「字幕」）。这一行上方有一条窄带，标出每一段的名字和起点。只能手动接。
  - 拖动画板标题可以移动画板。拖到另一块画板的一行中间，提示拼在这一行的上方或下方；拖到某一段的开头或结尾附近，提示接在前面或后面；松手就拼上。单位不同、或者想把好几行的画板左右接时，会说明原因，松手只是摆在那里。
  - 每个根都有「拆出」：单独一行的在层名旁边，接续的在窄带的名牌上。拆出的画板放在原画板正下方；拼走的画板留下的空当会被下面的画板补上。拖到别的画板边缘附近会自动对齐。
### 操作

拖动空白处平移（按住空格也能在画板上拖）；在尺子上拖可以圈出一段（Esc 取消）；滚轮缩放画布；Alt+滚轮只缩放鼠标下那块画板的时间；画板标题上的 − 适应 ＋ 也是缩放时间。画板左边移出视口时，层名一列会贴在视口左边。顶栏的「全部」显示所有画板；右上角的小地图可以拖动、缩放。
### 键盘

选中对象后，←/→ 选中同一轨道的前一个、后一个（左右接续时跨段接着走），↑/↓ 选中上一条、下一条轨道上离这一刻最近的对象；没选中对象时，←/→ 让播放头在剪辑点（对象的开头、结尾）之间跳。[ / ] 让播放头跳到插件给的上一个、下一个跳转点（接缝插件给的是接缝）。镜头只在目标出了画面时才跟过去。
### 复制链接

（顶栏）：把现在看的位置写成一个地址——当前画板、看得见的那段时间、播放头、选中的对象、对准的批注。贴给 AI，它用 `view_screenshot --link` 就能拍到同一个画面；浏览器不让写剪贴板时，地址会显示出来让你手动复制。
### 此刻

（右侧第一个标签）：点画板上任意位置，列出这一刻这块画板每层都有什么，视频会显示这一刻的画面；点色块会展开对象详情（含指向它的批注和它的关系）。标题旁的「复制文字版」把这一刻（圈出了一段就是那一段）每层是什么、怎么连着、哪些批注指着它们复制成文字，贴给 AI；和 AI 用的 `view_at` 是同一份。这一刻没有对象的层写一行是哪种空："空着：6–9（3 秒）"是两个对象之间空着，"已经结束""还没开始"是在这层第一个对象之前或最后一个之后；整层都没有对象的容器层不写。播放头只在当前画板上，用这块画板的单位；落在接续的行上时，同时写出是哪一段的第几秒。
### 改动

（右侧第二个标签）：列出最近 1～100 次操作改了什么——新建、删除、移动（前后位置）、改了哪些字段（information 里改了的键给出前后值）。打开时画布上标出改过的对象（角上的数字是倒数第几次操作），删除或移动之前的位置画成虚线框。点列表里的一条，镜头飞到那个对象或那个虚线框上。只读 changes 日志。
### 批注

（右侧第三个标签）：按楼列出批注，可以只看待处理、已处理或"等我回复"的楼。先选中一个对象、点一个层名，或者在尺子上圈出一段，再写，批注就指向那里；什么都不选就是写给整个项目。每条都能回复，回复按楼显示（"3 楼 回复 2 楼"）；勾上楼主表示整楼已处理；改、删、回复都在卡片里完成（不用浏览器弹窗）。画布上，有待处理批注指着的色块和层名标 💬，指向一段时间的批注画成黄色的带子（带子不挡点击，下面的对象照样点得到；点两边的竖线或标签打开那一楼）；挂错了用楼主上的「改指向」改到现在选中的东西上，楼号、回复、已读都不变；点批注里的目标，镜头飞过去；点楼主上的「定位」，镜头框住这一楼指的全部地方，目标标成橙色虚线。
### 沿读

（右侧第四个标签）：从一个对象或一楼批注出发，顺着关联一步步往外读——它指着谁、谁指着它、再往外一步……批注指着对象、回复指着批注也都是关联，所以楼也能顺着读。入口是对象详情（「此刻」里选中的对象）和楼主卡片上的「沿读」。按步数分组列出每一步的名字、所在层、位置、文字或文件，以及是从哪一个、顺着哪条关联（带说明）到的；可以只看一个方向（它指着谁 / 谁指着它），步数 1～5。点「去看」：对象就选中并飞过去，层就对准它，批注就对准它那一楼；「从这里读」换成从这一步出发。和 AI 用的 `view_walk` 是同一份结果。
### 批注提醒

按本机的署名（批注面板里填，默认「用户」）算"等我回复"的楼——还没处理、最后一句不是你说的，并且你尚未标已读，和 `view_note --waiting` 是同一条规则。标已读后不再提醒；后来有新回复时会再次提醒。批注标签上的红色数字、浏览器标签页标题前的 (2)、楼上的「等你回复」都是它。别人（比如 AI 用 `view_note`）写了新批注或回复时，右下角弹一条提示，点一下打开那一楼。
### 关系线

数据里的关联（bind）画成带箭头的线，跨画板也画；连到层的线接在层名上。平时只画选中对象的关系，顶栏勾上「关系线」画出全部。选中对象的详情里列出它的关系，点一条跳过去；另一头在别的项目时，色块角上标 ↗。
### 接缝

（选装 layerweave.cuts 后出现的顶栏标签；项目里没有图片和视频时不显示）：同一条轨道里前后相接的图片和视频，把上一段的最后一帧和下一段的第一帧并排，写出两边的时间、是紧接还是中间空着；接续的两段之间也算。用来查衔接——比如上一段球落在地上，下一段却从桌上开始。点一个接缝回到画布上的那个位置。
### 找对象

顶栏的搜索框按名字、文字、文件名或 `#编号` 找，回车跳到下一个，Shift+回车上一个。
### 预览

（选装 layerweave.preview）：把一个文件里的帧罗列出来——视频、会动的 SVG（SMIL 或 CSS 动画；脚本驱动的不行）、GIF / 动态 WebP / APNG。默认逐帧缩略图；可以改开始的秒、间隔（逐帧、每几帧、每几秒）和帧率（视频按播几帧量出来的，量不到用 24）。一页一屏（默认 48 张，可换 24、96）。左边列出候选：视频在前；目录里勾了层时只列那几层的。只看一个文件里的帧，不把几层叠起来合成。AI 自查一段：`view_screenshot … --view layerweave.preview --param object=812 --param from=12 --param step=1f`（step 也可以写 `3f`、`0.5s`；另有 `fps=`、`per=`、`page=`）。
### 一览

（选装 layerweave.assets；地址使用 `view=layerweave.assets`）：按种类列出项目里所有的对象，像资源管理器一样用网格显示图片、视频封面、音频波形和文字；可以按类型筛选，点一下回到画布上的对应位置。分页：一页 60 张（可以换 30、120），对象再多也只排一页的；截图拍第几页用 `--param page=3`。一览由选装插件 layerweave.assets 提供。
- 每两秒轮询业务变化和排版变化；正在写入或拖动时延后应用，结束后从原游标继续。

画板排版写入项目库；镜头、当前选择、语言与插件清单继续保存在本机。旧 `~/.layerweave/view/<数据库路径的散列>.layout.json` 作为迁移来源保留。

文件路径：`information.source` 是绝对路径就直接用，是相对路径就相对于数据库文件所在的目录；网址不经本机服务提供。服务只提供数据库里引用过、而且确实存在的文件，支持 Range 请求，所以视频可以拖动进度。

## 选装 FFmpeg

FFmpeg 是外部可执行程序，不随 LayerWeave wheel 提供，安装 mcp extra 或使用 uv 也不会自动装入它。由使用者按需安装；基础数据读写、文本展示和关联管理不依赖它。

| 功能 | 有 FFmpeg | 没有 FFmpeg |
|---|---|---|
| 图片缩略图 | 服务端按需缩小并缓存；SVG/GIF 保留原图 | 发送原图，加载量可能更大 |
| 音频波形 | 服务端计算并缓存波形数据 | 浏览器下载音频并尝试解码，受支持格式限制 |
| 视频封面与当前帧的浏览 | 服务端抽帧 | 回退到浏览器解码，受支持格式及加载进度限制 |
| view_frame 提取一帧 | 可以执行 | 明确报告找不到 FFmpeg |

Windows 用户可从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)列出的 Windows 构建来源获取并解压。需要能运行的 ffmpeg.exe；安装同名 Python 包不能代替它。将其 bin 目录加入 PATH，或在启动 LayerWeave 的 PowerShell 中设置实际可执行文件路径：

```powershell
$env:FFMPEG = 'D:/tools/ffmpeg/bin/ffmpeg.exe'
& $env:FFMPEG -version
```

路径换成自己的安装位置；FFMPEG 指向文件，不是 bin 目录。在同一窗口启动视图服务即可继承这个变量。若使用 PATH，可运行 `ffmpeg -version` 验证；修改系统环境变量后，重新启动原来已打开的终端或 MCP 客户端。

若由 MCP 客户端启动，在该客户端的 LayerWeave 服务项 env 中加入 `"FFMPEG": "D:/tools/ffmpeg/bin/ffmpeg.exe"`，保留其他环境变量，再重启服务。这里是客户端启动配置，不是 LayerWeave 的 mcp.json；完整配置入口见[MCP 安装与启动](../shared/mcp/README.md#安装与启动)。程序优先采用有效的 FFMPEG 文件路径，其次查 PATH；磁盘上有文件但这两个入口都未提供时，程序仍会认为未安装。

外置技能另有依赖时，以各自 SKILL.md 为准。FFmpeg 不会代替 AI 截图需要的 Chrome、Edge 或 Chromium。

## 给 AI 用

用户说“这里”“这一刻”时，先用 `view_at` 读取当前内容，需要镜头与选择状态时用 `view_state`；用户提供视图链接时用 `view_screenshot --link`。批注、引用与画面可以互相定位。

| 工具 | 何时使用 |
|---|---|
| `view_state` | 读取用户当前项目、画板、选择、播放头及语言 |
| `view_at` | 读取某个根的时刻或区间；不传范围时读取用户正在看的位置 |
| `view_walk` | 从对象、层或批注出发沿关联展开；控制方向、深度与数量 |
| `view_note` | 查询、创建、回复、改指向、已读与处理批注 |
| `view_fold` | 查询或改变人和 AI 两边的折叠状态 |
| `view_layout` | 读取画板位置和实际宽高，调整尺寸、邻接放置、拼接、拆分、移动、重置或迁移旧布局 |
| `view_screenshot` | 拍当前画布、指定范围、批注目标或已安装插件的页面 |
| `view_frame` | 从视频对象提取一帧；需要 FFmpeg |
| `view_plugin` | 查询、安装、更新和管理选装插件，见[插件说明](PLUGINS.md) |
| `view_tables` | 检查工具表声明；旧库需要时显式 `--upgrade` |
| `view_bench` | 开发时验证交互性能，见[性能说明](PERFORMANCE.md) |

完整参数和返回从实际命令声明查询，不在本页复制全部参数表：

```sh
python -X utf8 -m layerweave.tool.builtin.shared.help.command_help view_at view_note view_screenshot --json
python -X utf8 -m layerweave.tool.builtin.view.screenshot --help
```

### 读取、批注与截图示例

以下命令分别展示一种调用，不是一套按顺序执行的脚本。DATABASE 换成数据库路径；项目 1、对象 16、层 1、批注 42 都是示意编号，使用前通过查询取得实际编号。输出路径由调用 AI 安排。

```sh
python -X utf8 -m layerweave.tool.builtin.view.state DATABASE
python -X utf8 -m layerweave.tool.builtin.view.at DATABASE 1 --root 1 --range 10 15
```

拍插件页面前先按[插件说明](PLUGINS.md)安装对应插件。例如一览分页使用 `--view layerweave.assets --param page=3 --param per=30`；接缝可用 `--view layerweave.cuts --full-page`；预览参数以插件自身 `info` 为准。页面、图片和媒体实际就绪后才会输出成功；目标不可用或超时会报错，不生成替代画布截图。

### 范围和数据边界

- 画板用根层编号指认：`--board 1` 表示根层 1 所在的画板。各画板使用自己的轴单位。
- 左右接续时，截图的 `--begin --end --playhead` 使用画板连续时间；`view_layout` 的 offset 是各段在画板上的偏移，`view_state.playhead_at` 给出根内位置。`view_at --root` 使用根自己的时间。
- 开始协作时可读 `view_note --waiting 自己的名字`；查看批注目标用 `view_screenshot --note`，追踪来龙去脉用 `view_walk`。
- 人和 AI 的折叠分别保存。AI 可以折叠自己这边、展开用户这边；用户折叠不表示可以省略内容检查。需要保留旧方案时，可将它移入单独根层并折叠，具体保留或删除由当前任务决定。
- 用户圈选区间后，用 `view_state.selection` 取得根与根内起止；可用 `view_note add --to layer:编号 --span 起点 终点` 附注。
- 修改圈选内容：取得根与起止 → [交换工具](../usage/exchange/README.md)按子树和区间导出，并带 `--include-baseline` → 修改 JSON → apply。更新原对象保持编号和批注关联，修改后用 `view_at` 或截图复查。
- 截图使用临时浏览器配置，不记录视图状态，不修改排版、批注和折叠。可用 `--browser` 或环境变量 `LAYERWEAVE_BROWSER` 指定 Chrome、Edge 或 Chromium。
- 排版、批注、折叠和已读记录通过统一写入入口保存到项目数据库；“正在看哪儿”和窗口偏好留在本机。结构见[开发说明](DEVELOPMENT.md)。

### AI 调整尺寸和位置

先查询 `view_layout show --json`，用返回的 roots 中的根层编号操作，board 是展示序号。结果给出世界坐标 x/y、width/height 和尺寸偏好；automatic=true 表示坐标是自动摆放预览。默认 viewer=user 按用户折叠计算完整布局，可用 --viewer ai 查看 AI 的折叠结果。实际窗口若筛选了层，`view_state.geometry` 给出当前可见画板的真实显示边界，`viewport` 给出镜头；它是带 age_seconds 的最近状态。

```sh
python -X utf8 -m layerweave.tool.builtin.view.layout DATABASE PROJECT_ID show --json
python -X utf8 -m layerweave.tool.builtin.view.layout DATABASE PROJECT_ID resize ROOT_ID --width 1800 --lane-height 180
python -X utf8 -m layerweave.tool.builtin.view.layout DATABASE PROJECT_ID place ROOT_ID --to OTHER_ROOT_ID --side right --gap 48
python -X utf8 -m layerweave.tool.builtin.view.layout DATABASE PROJECT_ID migrate
```

编号替换为查询返回值。width/height 调整整块画板的目标尺寸；pps/lane_height 分别直接设置横向比例和对象行高。同一方向只需一种参数。place 是邻接放置并避让，允许不同单位画板并排；merge 才是按同一轴合并，仍要求单位相容。move 接受明确 x/y，允许有意叠放。有实际变化时返回 operation_id，相同值不产生新日志；MCP 中 show 经 query，其他这些动作经 edit。
