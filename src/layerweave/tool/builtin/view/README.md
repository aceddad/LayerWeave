# 内部工具 · 视图工具

只读的本机网页视图，以及给 AI 用的截图、取帧、"用户正在看哪儿"三个工具。[返回内部工具导航](../README.md)。

视图只读：服务只监听 127.0.0.1，用只读方式打开数据库，不写业务库，也不产生 changes 日志。要修改项目内容，仍然用使用工具。只用 Python 标准库；网页不需要构建，直接随包分发（`web/`）。

## 给人看：视图网页

```sh
python -m layerweave.tool.builtin.view.server DATABASE [--project 1] [--port 8765]
```

用浏览器打开打印出来的地址。

- **时间轴**：层按父子顺序排成轨道，有子层的可以折叠；对象是轴上的色块。同一层里互相重叠的对象会分成上下几行。图片显示缩略图，视频显示封面，音频显示波形，文字直接显示；素材文件不存在的对象用斜纹标出。
- **此刻面板**：点时间轴上任意位置，右侧列出这一刻每层都有什么，视频会显示这一刻的画面；点色块会展开对象详情。
- **素材**：像资源管理器一样，用网格显示图片、视频封面、音频波形和文字；可以按类型筛选，点一下回到时间轴上的对应位置。
- 数据库被工具修改后，两秒内自动刷新。

素材路径：`information.source` 是绝对路径就直接用，是相对路径就相对于数据库文件所在的目录；网址不经本机服务提供。服务只提供数据库里引用过、而且确实存在的文件，支持 Range 请求，所以视频可以拖动进度。

视频画面：本机有 ffmpeg（在 PATH 里，或用环境变量 `FFMPEG` 指定）时，封面和"此刻"的画面由服务端抽帧，结果稳定，截图也拍得到；没有 ffmpeg 时，交给浏览器自己解码。

## 给 AI 用

| 工具 | 用途 |
|---|---|
| `view_state` | 用户正在看哪儿：项目、视图、可见范围、播放头、选中的对象、可见的层。用户说"这里""这段"时先读它 |
| `view_screenshot` | 把视图截成 PNG：时间轴或素材网格，可指定时间范围、层、播放头、选中对象。截图页面不记录状态 |
| `view_frame` | 取视频对象在某一刻的画面（JPEG），按时间轴全局时间或视频自身时间；需要 ffmpeg |

```sh
python -m layerweave.tool.builtin.view.state DATABASE
python -m layerweave.tool.builtin.view.screenshot DATABASE 1 输出.png --begin 8 --end 14 --playhead 10
python -m layerweave.tool.builtin.view.frame DATABASE 1 16 输出.jpg --at 3.75
```

- 截图自动查找 Chrome、Edge 或 Chromium，也可以用 `--browser` 或环境变量 `LAYERWEAVE_BROWSER` 指定。浏览器使用临时的独立配置，不会碰到用户正在用的浏览器。
- "正在看哪儿"记在本机用户目录 `~/.layerweave/view/` 下，每个数据库一份，不写进业务库。
