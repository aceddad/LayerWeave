# 内部工具 · 视图工具

只读的本机网页视图，以及给 AI 用的四个工具：截图、取帧、画板排版、"用户正在看哪儿"。[返回内部工具导航](../README.md)。

视图只读：服务只监听 127.0.0.1，用只读方式打开数据库，不写业务库，也不产生 changes 日志。要修改项目内容，仍然用使用工具。只用 Python 标准库；网页不需要构建，直接随包分发（`web/`）。

## 给人看：视图网页

```sh
python -m layerweave.tool.builtin.view.server DATABASE [--project 1] [--port 8765]
```

用浏览器打开打印出来的地址。

- **画布**：一张可以拖动、缩放的画布。每个根层连同它的子树是一块**画板**，画板里是这个根的时间轴：层按父子顺序排成轨道，有子层的可以折叠；对象是轴上的色块。同一层里互相重叠的对象会分成上下几行。图片显示缩略图，视频显示封面，音频显示波形，文字直接显示；素材文件不存在的对象用斜纹标出。
- **拼接**：单位相同的根默认拼在同一块画板里，上下排列，共用一把尺子和一根播放头，同一个数值上下对齐。"秒"和"s"这类同义写法算同一种单位；没有单位的根各占一块，不参与拼接。
  - 每一段的根层名字旁边有「拆出」，点了就单独成一块画板。
  - 拖动画板标题可以移动画板；拖到另一块单位相同的画板上，会提示拼在哪一段的上方或下方，松手就拼上。单位不同时会说明原因，松手只是摆在那里。
  - 左右不拼接：左右摆放只是位置，不表示先后播放。拖到别的画板边缘附近会自动对齐。
- **操作**：拖动空白处或轨道可以平移；滚轮缩放画布；Alt+滚轮只缩放鼠标下那块画板的时间；画板标题上的 − 适应 ＋ 也是缩放时间。画板左边移出视口时，层名一列会贴在视口左边。顶栏的「全部」显示所有画板。
- **此刻面板**：点画板上任意位置，右侧列出这一刻这块画板每层都有什么，视频会显示这一刻的画面；点色块会展开对象详情。播放头只在当前画板上，用这块画板的单位。
- **素材**：像资源管理器一样，用网格显示图片、视频封面、音频波形和文字；可以按类型筛选，点一下回到画布上的对应位置。
- 数据库被工具修改、或者排版被 AI 改了以后，两秒内自动刷新。

画板的拼接、拆分、位置和时间缩放存在本机用户目录 `~/.layerweave/view/<数据库路径的散列>.layout.json`，不写进业务库。

素材路径：`information.source` 是绝对路径就直接用，是相对路径就相对于数据库文件所在的目录；网址不经本机服务提供。服务只提供数据库里引用过、而且确实存在的文件，支持 Range 请求，所以视频可以拖动进度。

视频画面：本机有 ffmpeg（在 PATH 里，或用环境变量 `FFMPEG` 指定）时，封面和"此刻"的画面由服务端抽帧，结果稳定，截图也拍得到；没有 ffmpeg 时，交给浏览器自己解码。

## 给 AI 用

| 工具 | 用途 |
|---|---|
| `view_state` | 用户正在看哪儿：项目、当前画板、可见范围、播放头、选中的对象、屏幕上的画板和层。用户说"这里""这段"时先读它 |
| `view_screenshot` | 把视图截成 PNG：整张画布、某一块画板（`--board`，可加 `--begin --end` 放大一段）或素材网格。等页面把图片、封面、波形加载完才拍 |
| `view_layout` | 查看或调整画板：同单位的根拼在一起（`merge`）或拆开（`split`）、移动（`move`）、恢复自动排版（`reset`）。和网页改的是同一份排版 |
| `view_frame` | 取视频对象在某一刻的画面（JPEG），按时间轴全局时间或视频自身时间；需要 ffmpeg |

```sh
python -m layerweave.tool.builtin.view.state DATABASE
python -m layerweave.tool.builtin.view.screenshot DATABASE 1 输出.png
python -m layerweave.tool.builtin.view.screenshot DATABASE 1 输出.png --board 1 --begin 8 --end 14 --playhead 10
python -m layerweave.tool.builtin.view.layout DATABASE 1
python -m layerweave.tool.builtin.view.layout DATABASE 1 split 19
python -m layerweave.tool.builtin.view.layout DATABASE 1 merge 19 --to 1 --side above
python -m layerweave.tool.builtin.view.frame DATABASE 1 16 输出.jpg --at 3.75
```

- 画板用根层编号来指：`--board 1` 是"根层 1 所在的那块画板"；子层跟着它的根走。
- 位置、播放头、时间范围都用对应画板的单位；不同画板的单位可能不同（比如一块是秒，一块是帧）。
- 截图自动查找 Chrome、Edge 或 Chromium，也可以用 `--browser` 或环境变量 `LAYERWEAVE_BROWSER` 指定。浏览器使用临时的独立配置，不会碰到用户正在用的浏览器；截图页面不记录状态，也不改排版。返回里的 `ready` 为 False 时，表示等待时间内没加载完，图里可能缺缩略图。
- "正在看哪儿"记在本机用户目录 `~/.layerweave/view/` 下，每个数据库一份，不写进业务库。

## 以后
