# 草图引导出图（SVG／代码草图 → 成图）

先用 SVG 或代码画一张平涂的构图草图，再把它和角色设定图一起作为参考图交给 `generate.py`，让成图服从草图里的构图和姿势。

## 适合用在
- 姿势细节：哪只手、手背还是掌心朝向观众、拇指朝哪边、谁在前面挡住谁。
- 空间布置：物体的倾斜角度、在画面里占多大、前景／中景／远景的层次。
- 整体构图：主体放在画面哪里、留白在哪里。

## 画法
1. 用 SVG 或代码画平涂的形状，不需要细节和光影。把前后遮挡关系画清楚：前面的形状完整，后面的形状被前面的切掉。
2. 可以用颜色区分身份，例如两个人的手各用一种颜色。在提示词里写明"草图里的颜色只用于区分，成图恢复正常肤色和服装颜色"。
3. 把草图栅格化成 PNG。任何能把 SVG 转成 PNG 的工具都可以，比如浏览器截图、Inkscape、cairosvg、resvg；也可以直接用 Pillow 等画布库在代码里画出 PNG。
4. 出图时把草图和角色设定图都放进 `--ref`，在提示词里写明：保留草图的构图、姿势、遮挡关系和留白，角色外观以设定图为准，画风以风格段为准。

```sh
python scripts/generate.py 成图.png 提示词.txt --model 模型名 --style 风格.txt --ref 草图.png 角色设定.png
```

## 管得到的和管不到的
- 管得到：手的朝向、拇指方向、露出几根手指、前后遮挡、物体倾斜和占画面多大、整体构图。只写文字时，模型往往能画对基本关系，但会按自己的理解改动姿势；加了草图，细节会更贴近设计。
- 管不到：解剖是否正确；画风能否守住（成图可能自行添加柔光、材质和环境细节）。
- 草图画得僵，成图也会僵。想要放松的手势，要先在草图里把关节弯曲和接触角度画出来。
- 草图没画清、提示词没说清的细节，模型会自己重新解释。这不算违反指令，下次把它画清或写清。

## 已有依据
多次独立的小试验，用过 API 和对话内置的出图工具：手部接触（两只手的朝向和遮挡）、三层空间（前景的手、空椅、镜中的人物）、角色站位构图。每个条件只生成过一张，没有固定随机种子。它们支持"草图能帮助锁定构图和姿势"，但不能推出整体成功率或画面质量提高了多少。
