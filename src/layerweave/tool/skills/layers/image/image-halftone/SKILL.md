# 网点画

依赖：`pip install -r requirements.txt`（numpy、Pillow）。从本技能目录运行。

输出图片、点数据和网格 JSON 的目录由调用的 AI 自行选择；先准备好目录，再显式填写各输出路径，建议使用绝对路径。

## 单张图

```sh
python scripts/halftone.py 输入.png 输出.png [--crop x0 y0 x1 y1] [--cell 14] [--color #FF2E88] [--background transparent] [--dots 点.json]
```

- `--crop`：先从原图裁出这一块，再放大到 `--size`（默认 1920x1080）。
- `--cell`：网格间距。越大，点越粗、越抽象。
- `--color`、`--background`：点的颜色；底色可以是 `transparent`，也可以是一种颜色（如 `#000000`）。
- `--dots`：另存每颗点的 `[x, y, 半径]`。动画代码读入后可以一颗颗画，做聚拢、散开、从一个点展开、逐颗出现等效果。
- 调整明暗：亮度低于 `--black`（默认 0.18）的地方不出点；`--range` 控制对比拉伸的范围；`--gamma` 大于 1 时中间调的点变小。`--invert` 让暗处出大点（白底黑点的效果）。`--blur` 在转换前去掉细碎噪点。
- 打印一行 JSON：输出路径、点数、网格间距、尺寸。

## 多张图共用一张网格

```sh
python scripts/halftone_grid.py 网格.json 图1.png 图2.png [...] [--crop x0 y0 x1 y1] [--cell 14] [--invert] [--gamma 2.2]
```

- 输出 `{"cell", "cols", "rows", "frames"}`。frames 里每张图一组半径（×10 取整），按行优先排列，奇数行错开半格。
- 同一格在不同图里一一对应，动画里对每一格的半径插值，就能逐点地从一张图过渡到另一张。
- 各张图要用同一个裁切框，位置才对得上。

## 用法经验
- 高对比、主体明确的部分转出来最好认，比如脸、手、剪影。大面积的中间调会变成一片均匀的点，失去层次。
- 亮的脸容易糊成一整块。这时提高 `--black`、加大 `--gamma`，或者换一个更紧的裁切框。
