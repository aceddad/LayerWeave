# 看视频：时间结构

只看几张抽帧时，不知道每张持续多久、两张之间发生了什么。这组脚本把"时间"变成能读的表和图。都是从本技能目录运行。

依赖：`pip install -r requirements.txt`（av、numpy、Pillow、scipy）。时长表另外需要 ffmpeg。

输出图表、JSON 和临时片段的位置由调用的 AI 按项目管理。先准备好输出目录，再显式传入 --out 前缀或 --json 路径，建议使用绝对路径；需要安排临时目录时使用 --tmp-dir。

## 先用哪个
- 审一段视频，默认先用 **review.py**：按内容切出状态和过渡，每张关键帧都知道自己管辖哪几帧、前后怎么接。
- 看单个主体的动作节奏（原画在哪、停多久、缓入缓出），用 **keys.py**。
- 想知道一共用了几张画、各停几拍、哪里接得太跳，用 **xsheet.py**。
- 看角色怎么进场、出场、有没有跳位，用 **actors.py**。
- 要精确的停留时长和过渡时长，而且画面干净时，用 **durtable.py**。

## review.py：带范围的关键帧拼图

```sh
python scripts/review.py 视频.mp4 [--start 秒 --end 秒] [--out 前缀] [--sens 1.0] [--font 字体文件]
```

- 输出 `前缀_review_N.jpg`（每页 12 个状态）和 `前缀_review.md`。
- 状态：画面不变或缓慢变化的一段，标出帧范围和时长。
- 过渡：标出帧数和类型，包括硬切、快切、淡化（亮度主导）、运动过渡（结构主导）、先快后慢、中途突跳；并附过渡中间的小图。
- 每个过渡还有两张图。洋葱皮是把过渡各帧叠在一起，青色是早、品红是晚：有一条从青到品红的连续路径，说明是有过程的运动；整幅同时变、没有路径，就是硬切或突变。变化热力图显示哪里在变：集中在主体上是主体在动，铺满全画面是换景或闪光。
- `--sens` 大于 1 时切得更细。图上的中文标注会自动找常见中文字体；找不到时用 `--font` 指定。

## keys.py：关键帧、停住、过渡

```sh
python scripts/keys.py 视频.mp4 [--out 前缀] [--hold 阈值]
```

- 输出 `前缀_keys.jpg`（速度曲线和关键帧缩略图）和 `前缀_keys.md`。
- 关键帧有三种：停住的段、速度降到局部低点（动作到位）、动作方向转折。
- 过渡标出帧数和最快的位置，分为缓出、缓入、两头慢、匀速、猛切。
- 比较的是线条结构（边缘和剪影），发光和调色不算动作。
- AI 生成视频的典型特征：关键姿势处速度降不到停住（"滑过去"），整段只有斜坡没有平台。
- 局限：适合单个主体。抽象画面里的慢速运动会被算成停住；平滑运动中间可能多报"方向转折"；硬切不会单独标出来，会和前后的停住并成一段。看切换请用 review.py。

## xsheet.py：自动摄影表

```sh
python scripts/xsheet.py 视频.mp4 [--penalty 1.0] [--out 前缀]
```

- 输出 `前缀_xsheet.jpg`（每张画的代表帧和停几拍）和 `前缀_xsheet.json`。
- `rough_joins`：某一次跳变比前后大 2 倍以上，说明这里缺中间帧，衔接太跳。
- `--penalty` 调大，分得越粗。

## actors.py：入场、离场、运动

```sh
python scripts/actors.py 视频.mp4 [--start 秒 --end 秒] [--out 前缀]
```

- 输出 `前缀_actors.md` 和 `前缀_actors.jpg`（轨迹泳道和入场离场缩略图）。
- 入场分为从边缘进入、由小变大、淡入、一帧闪现，离场同理；运动分为跳位、缓出缓入、匀速、抖动。
- 适合纯色或接近纯色的背景：和背景色差异大的连通区域算一个"演员"。
- 局限：分不清人物和文字，歌词块也会被当成演员；挨在一起的元素会粘成一个，可能误报跳位。

## durtable.py：时长表

```sh
python scripts/durtable.py 视频.mp4 [--start 秒 --end 秒] [--json 输出.json] [--ffmpeg ffmpeg路径] [--tmp-dir 临时目录]
```

- 列出每段停留和变化的帧范围、时长，以及之间的切换方式。
- 需要 ffmpeg：默认在 PATH 里找，也可用 `--ffmpeg` 或环境变量 `FFMPEG` 指定。截取片段时会写临时文件，用 `--tmp-dir` 可以指到空间充足的盘。
- 局限：只在"干净渲染、只有主体在变"的画面上可信。画面别处同时有东西在动、有颗粒、或是 AI 生成视频时，会报成"全是变化"。在真实素材上测试时没有达到合格线，适合当补充检查，不要当唯一依据。
