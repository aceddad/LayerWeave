# 技法讲解

## 为什么用真实轮廓
把文字当成一个整体框来缩放或倾斜，看起来只是"字变形了"。把每个字形的轮廓点都交给同一个变形函数，变形就能穿过字与字之间：例如右端钉住、左边被压扁，或者中间鼓起来。字就像一个有重量的物体在受力。

## 力的传导
- 给变形函数传入"第几个字"，让每个字晚一点点受力（例如每个字晚 9 毫秒）。力会从受力端沿着单词传过去。
- 受力的方向和画面里的东西对应：撞到墙上就是右端钉住、从右往左压；被拉开就是两头往外。

## 先切后弯
- 切口要在变形之前做，切在原始轮廓上，再对切好的两半分别变形。先变形再用遮罩切，切口会跟着变形歪掉，看起来像被擦掉，而不像被切开。
- 同一个单词画两次（一次保留上半、一次保留下半），各自移动，中间露出的空隙可以放别的画面，例如睁开的眼睛。

## 定格式的受力
- 受力只发生在重音那一下：到达、峰值、回弹、静止。不要让字一直晃动或漂浮，那样重音反而不明显。
- 连续几次重音可以逐次加大：字更宽、更高、角度更斜，同时留下前几次的痕迹，例如墙上的裂纹。

## 斜向窗格碎裂
- 把同一份画面裁成斜向的窗格（CSS `clip-path`），每格带透视（`perspective` 加 `rotateY`）依次飞走。被移动的就是画面本身，所以碎片和原画面不会对不上。
- 飞走的顺序可以从中间向两边，跟着重音一组一组地走。原来的接缝可以单独画成细线，留在原处。
