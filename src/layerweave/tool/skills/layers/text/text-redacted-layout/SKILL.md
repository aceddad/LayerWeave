# 涂黑排版检查

依赖：`pip install -r requirements.txt`（fonttools、av、numpy、Pillow）。从本技能目录运行。

涂黑字体和预览文件的输出目录由调用的 AI 自行选择并准备，调用时显式传入路径，建议使用绝对路径。检查脚本的文字结果输出到标准输出，需要保存时由 AI 决定位置。

## 思路
排版只取决于每个字的宽度和字距，而不取决于字长什么样。把字体里每个字形换成同宽的方块，排出来的位置、断行、沿路径的长度就和原字体完全一样，只是认不出字。这样，看预览的人或 AI 就能检查版式，却读不到原文。

## 1. 生成涂黑字体

```sh
python scripts/make_redacted_font.py 原字体.ttf 涂黑字体.ttf
```

- 字母和数字换成实心方块：大写和数字用大写字母的高度，其他用小写字母 x 的高度（中文也算在这一类）；标点换成小方块；空格不变。每个字的字宽保持原样。
- 只支持 TrueType 轮廓（带 glyf 表的 .ttf）。CFF 轮廓的 .otf 需要先转成 TTF。
- 实测：同一行中英混排的文字，原字体和涂黑字体排出来的宽度完全相同。

## 2. 用涂黑字体渲染预览
在工程里加一个开关，让文字层改用涂黑字体，其余一切不变，再渲染预览。检查文字的位置、断行、和画面的避让、出入场时机。确认没问题后，切回原字体出正式版。

## 3. 闪烁扫描

```sh
python scripts/text_flicker.py 底片.mp4 带字版.mp4 [另一个带字版.mp4 ...]
```

- 底片是不带文字的版本，带字版是同一工程叠上文字的版本。两者要同尺寸、同帧率、逐帧对齐。
- 逐帧做差，得到文字的像素面积，找出"中间一帧明显少"（drop，换句时文字掉了一帧）和"中间一帧明显多"（spike，残影）的帧，打印时间和帧号。只输出数字，不输出画面。
- `--threshold` 调整多大的灰度差才算文字像素，`--min-area` 调整两侧至少要有多少文字像素才判断。

## 4. 检查源码里有没有写死原文

```sh
python scripts/find_hardcoded_text.py 原文.srt 源码文件 [源码文件 ...]
```

- 原文可以是 SRT 字幕，也可以是 JSON：字符串列表，或带 `text` 字段的对象列表。
- 找出源码中引号里与原文重合的片段，只打印"文件:行号"和重合的字符数，不打印原文本身。原文应该由运行时从字幕文件读入，而不是写进代码里。
