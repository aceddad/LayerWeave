# 子树与迁移的实现

用户调用和结果格式见[子树工具](../../tools/usage/SUBTREES.md)、[跨项目工具](../../tools/usage/EDITING.md)。[返回存储模块](README.md)。

## 共享步骤

[subtrees.py](subtrees.py) 在一次 run_operation 中组合范围读取、CRUD 和日志：

| 函数 | 职责 |
|---|---|
| _source | 用 read_project_details 取得子树记录和所属实体的出向关联 |
| _ordered_layers | 迭代排序层结构；访问集合避免深树递归和已有环的重复展开 |
| _copy_records | 创建层、完成内部父引用，再创建对象和关联；保存实际新编号映射 |
| _delete_records | 按关联、对象、子层到父层的顺序删除，延后外键验证到事务最终状态 |
| _transfer_records | 共用复制、外部入向改指与源删除步骤 |

transfer_objects 构建不含层的选择记录，复用这些步骤并显式提供目标层。层不会被隐式纳入复制范围。

## 实现约定

- 编号映射取实际创建结果，不预测 max_id；实体身份映射同时考虑种类和项目。
- 在对象写入前完成副本的 father 关系，使普通复制的 PositionMath 使用最终轴环境。
- 先收集外部入向关联并排除范围内实体拥有的关联，再执行迁移；避免同一关联同时作为复制项和外部改指项处理。
- 自关联、互相引用和已有父链环使用相同映射，已有问题由提交后检查报告，不在复制时猜测修复。
- 树内外关联的对外语义只在使用说明维护；SCHEMA 负责发号、编码与日志写入约定。

验证重点是实际编号映射、最终外键状态、整批失败回滚以及 undo/redo 对两个项目和外部关联的恢复。
