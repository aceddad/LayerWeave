# 内部工具 · 视图工具

本目录当前只有分类说明，没有 GUI 依赖、可执行工具或命令声明。[返回内部工具导航](../README.md)。

未来视图工具可以负责显示/隐藏、选择/取消选择、定位、展开/折叠和视口缩放。实际可视状态由视图管理；配置中的 visibility 仍只描述是否允许显隐控制，不把 visible 放回基础模型。

项目概览、详细展开及所有内容编辑已经属于使用工具。界面需要修改项目内容时复用这些工具，不另建一套存储、编号、检查或撤销逻辑。

开始可视化实现时按用户要求建立独立 visualization 分支；非可视化 main 保持可单独运行。MCP 编排留到对应封装阶段讨论。
